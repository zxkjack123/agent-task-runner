固定执行程序（PM #2622 流水线 Step 契约 — 逐字执行，不得增删步骤）

你的任务：对 task_card.context_files 中 doc: 指令指向的文档执行「只读提交前检查」，
产出 A/B 分级报告。你不修复文档，不改任何文档内容。

【P0 前置门】（任何一项失败 → 走哨兵路径，见文末"哨兵书写规范"）
  1. 调用 manuscript-lint 的 list_rules；断言 tier1_tools 数组长度 == 14。
     14 个工具名必须为：fig_table_audit / section_presence / citation_integrity /
     ref_statistics / acronym_audit / provenance_coverage / formatting_audit /
     language_audit / structure_audit / weak_expression_audit / em_dash_audit /
     can_avoidance_audit / dead_noun_audit / future_work_vague_audit。
     长度 != 14 → PRECONDITION-FAILED。
  2. 文档路径（task_card.constraints 中 "doc: 指令路径 = '<p>'"）必须存在；
     相对路径相对于 workspace_path 解析；该路径必须位于 git 项目内
     （路径或其祖先目录含 .git）。失败 → PRECONDITION-FAILED。

【Step 1】manuscript-lint full_scan(path=文档路径, profile 按 doc: 类型映射：
  doc:paper→paper、doc:patent→patent、doc:report→report)。

【Step 2】citation-lint full_scan(path=文档路径同级目录的 .bib 文件)；
  若文档无对应 .bib 文件 → 报告记 "citation-lint: N/A（无 .bib）"，不视为失败。

【Step 3】formatforge 按文档扩展名路由（只调一个）：
  .docx → validate_docx(docx_path=文档路径)；.tex → validate_latex(latex_path=文档路径)；
  .md → lint_markdown(markdown_path=文档路径)。

【Step 4】汇总 + 分级（分级表见下）：
  - 逐 finding 标记 A/B；分级表未列出的规则 ID → B（保守默认）。
  - 写报告 <workspace_path>/.github/reports/doc-pipeline-T{task_id}-<yyyymmdd>.md
    （yyyymmdd=当天 UTC 日期；目录不存在则创建）。
    报告列头（EC-7 固定）：规则ID | A/B | 位置(文件:行) | 证据 | 建议修复 | severity
    表格后附：① B 类清单及人工处置建议；② Gate D.2 S1-S8 自检摘要表
    （每条标 通过/需关注 + 一句话证据）。
  - pm_task_update(触发任务 task_id, notes 追加："doc-pipeline 报告: <报告相对路径>"
    + A 类/B 类计数摘要)。
  - git add + commit 仅报告文件（commit message: "docs: doc-pipeline report
    T-{task_id}"）。流水线对文档只读——git diff 中只允许出现报告文件。

【Step 5】闭环路由：
  - A 类非空 → pm_task_create(title="doc-fix: <文档名> A类缺陷修复",
    project=pm_detect_project(workspace_path) 结果，检测不到则沿用触发任务项目,
    tags=["auto", "doc-fix"],
    notes 必须含以下三行（各占一行）：
      workspace: <workspace_path 绝对路径>
      报告: .github/reports/doc-pipeline-T{task_id}-<yyyymmdd>.md
      文档: <文档相对 workspace_path 的路径>
    + 报告 A 类节选 + 修复约束(只修A类/B类不修/protected region跳过/不新增内容)
    + re-lint 要求 + KB dataset_id f6b0a969-945f-4ccc-83c2-62f2b687a025)。
    恰好创建 1 个，不重复创建。
  - A 类为空（仅 B 类或零 finding）→ 不建子任务；B 类非空则
    pm_notify(title="doc-pipeline B类待人工", message=报告路径+B类计数, severity=warning)。
